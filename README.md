# Sudoku

Веб-приложение судоку: Rails API, PostgreSQL и React/Vite.

## Описание проекта

Sudoku Club — браузерная игра для одного игрока с аккаунтом, сохранением текущей партии и общим рейтингом решенных игр. Цель проекта — показать полный путь игрока от регистрации до завершения судоку и сохранения результата, а также работу клиентского интерфейса, серверного API, базы данных и обновления данных в реальном времени.

## Экраны и переходы

```text
Вход ⇄ Регистрация
  ├─ UI Kit → Назад к предыдущему экрану
  └─ Успешный вход → Игровой экран
                      ├─ Новая игра / выбор сложности → Новая партия
                      ├─ Таблица лидеров → Закрыть / Продолжить игру
                      ├─ Решение судоку → Сохранить результат → Таблица лидеров
                      ├─ UI Kit → Назад к игре
                      └─ Выход → Вход
```

## Стек технологий

- **Фронтенд:** React 18, JavaScript (JSX), Vite, CSS, Lucide React; Action Cable JS подключает live-обновление лидерборда.
- **Бэкенд:** Ruby on Rails 7.2 в режиме JSON API, cookie-сессии, Rails Action Cable.
- **База данных:** PostgreSQL 16, Active Record, JSONB-сетки и заметки, миграции и индексы.
- **Запуск:** Docker Compose поднимает PostgreSQL, Rails API и Vite; приложение открывается по адресу `http://localhost:5173`.

## Подводные камни и сложная логика

- **Генерация головоломок:** внешний датасет не нужен. Алгоритм строит полное решение, удаляет клетки и проверяет, что у получившейся задачи осталось ровно одно решение. Проверка уникальности увеличивает время генерации сложных уровней.
- **Согласованность игры:** сервер проверяет размер сеток, решение судоку, исходные подсказки и завершенную доску. Клиент хранит заметки, ошибки и время вместе с партией; активная партия автоматически сохраняется в аккаунт и локальное хранилище браузера.
- **Вход и браузерная безопасность:** фронтенд и API работают на разных локальных портах, поэтому нужны CORS и cookie сессии с учетными данными. Разрешенный origin задается в Docker Compose.
- **Обновления лидерборда:** завершение партии сохраняется в PostgreSQL, после чего Rails Action Cable рассылает событие; открытые клиенты перечитывают рейтинг без перезагрузки страницы.
- **Автопауза:** таймер зависит от видимости вкладки; скрытие приложения останавливает ход времени до ручного продолжения.

## Запуск на другом компьютере

1. Установите Docker Desktop и запустите его.
2. Скопируйте папку проекта на компьютер (или клонируйте репозиторий).
3. В терминале из папки проекта выполните:

   ```sh
   docker compose up --build
   ```

4. Откройте <http://localhost:5173>.

При первом запуске Docker скачает образы и библиотеки, поэтому запуск может занять несколько минут. Остановить приложение: `Ctrl+C`; удалить контейнеры: `docker compose down`. Данные таблиц сохраняются в Docker volume и переживают перезапуск.

После изменения зависимостей фронтенда перезапустите его через `docker compose up -d --build web`. Контейнер проверит `package.json`, установит недостающие пакеты и запустит Vite.

## Запуск через GitHub Codespaces

Codespaces запускает среду разработки на виртуальной машине GitHub, поэтому Docker Desktop на компьютере, с которого открывают игру, не требуется.

1. Загрузите проект в GitHub и выберите **Code → Codespaces → Create codespace on main**.
2. Конфигурация `.devcontainer` установит Ruby и Node.js, запустит PostgreSQL и подготовит Rails API вместе с React.
3. Откройте вкладку **Ports**. Порт `5173` будет переслан автоматически; для показа преподавателю измените его видимость на **Public** и отправьте ссылку на этот порт. Порт API `3000` оставьте **Private**.

Фронтенд обращается к Rails через Vite proxy, поэтому для браузера сайт и API доступны с одного адреса. Подробности о создании dev container и пересылке портов есть в [документации GitHub Codespaces](https://docs.github.com/en/codespaces/setting-up-your-project-for-codespaces/adding-a-dev-container-configuration/introduction-to-dev-containers) и [руководстве по портам](https://docs.github.com/en/codespaces/developing-in-a-codespace/forwarding-ports-in-your-codespace).

Codespaces — среда для разработки и демонстрации, не постоянный хостинг: она останавливается при бездействии. Остановите Codespace после показа, чтобы не расходовать доступное время работы.

Для локальной разработки откройте <http://localhost:5173>; Rails API доступен на <http://localhost:3000/api/v1>.

## Возможности

- Генерация уникальных судоку четырех уровней, таймер и пауза при скрытии вкладки.
- Выделение клетки, ее строки, столбца, блока и совпадающих цифр.
- Ввод клавиатурой и мышью, заметки-кандидаты и их автоматическое удаление.
- Проверка конфликтов, до трех ошибок, подсказки, отмена и повтор хода.
- Автосохранение активной партии в PostgreSQL, таблица лучших результатов.
- Светлая и темная темы, включая системную тему.
- Регистрация и вход с cookie-сессией, профиль игрока и выход из аккаунта.
- UI Kit с палитрой, шрифтами, игровыми состояниями, кнопками и формами.
- Обновление таблицы лидеров через Action Cable без перезагрузки страницы.
- Автоматические тесты моделей и интеграционные сценарии регистрации, игры и контроля доступа.
